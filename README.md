# 个人简历与作品集页面

一个以单页网页呈现个人简介、项目卡片、技能与奖项信息的简历作品集，采用黑白手绘风格和轻量交互，便于访客快速浏览页面内容。

> 页面当前展示的姓名为“陈予安”，并包含学校、项目、奖项等自述内容。此草稿只描述仓库中可见的实现，不代表这些资料已经核验；发布前请确认内容准确并获得相关人员授权。

## 页面内容与交互

- **简介与意向**：页面展示 Frontend / Product Design 方向、教育/求职状态及地点等信息。
- **项目展示**：包含校园二手交易平台、AI 学习助手小程序、数据可视化大屏和作品集网站等项目卡片；卡片内容列出相应技术标签与项目亮点。
- **其他栏目**：包括奖项、技能、推荐语、个人介绍和联系区域。
- **页面交互**：顶部锚点导航支持平滑滚动；窄屏布局提供折叠菜单；明暗主题切换会将选择保存在浏览器 `localStorage`；项目卡片支持点击/悬停翻面，页面区块进入视口时显示，并含有指针/触摸跟随的首页遮罩效果。
- **视觉呈现**：黑白配色、手写风格字体、卡片式布局与响应式排版。

## 技术与文件

这是一个以 HTML、CSS 和原生 JavaScript 构成的静态页面项目。主页面位于 `pages/index.html`，样式变量见 `colors_and_type.css`。页面还引用 Tailwind CSS、Lucide 图标和 Google Fonts 等外部资源；相应在线资源在本地预览时需要网络连接。

仓库未包含 `package.json`、依赖清单或构建脚本，因此没有证据表明需要安装项目依赖或执行构建。可直接在浏览器打开 `pages/index.html` 进行静态预览。若浏览器对本地文件加载外部资源有限制，可使用任意静态文件服务器提供该目录；该仓库未声明特定服务器命令。
